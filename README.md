# SIMon-mobile-Homeassistant
Mit dieser Integration können Sie die Nutzung von Gesprächsminuten, SMS, Datenvolumen und weitere Informationen Ihres SIMon mobile-Mobilfunkvertrags über Home Assistant überwachen.

Dieses Projekt ermöglicht die Überwachung der Minuten-, SMS- und Datennutzung Ihres SIMon-mobile-Mobilfunkvertrags über Home Assistant. Ich hoffe, dass diese Integration auch für Sie hilfreich sein wird.
